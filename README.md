# 쉬운 국어 학습지 (120차시)

지체부자유 학생을 위해 초등학교 4~6학년 국어 내용을 쉬운 수준으로 낮춘 웹 학습지입니다.
설치 없이 `index.html`을 열거나, GitHub Pages 주소로 접속하면 바로 쓸 수 있습니다.

## 구성

12단원 × 10차시 = 120차시. 차시마다 **활동 3개(읽기 글 3편 + 문제 12개)** 로, 모두 글 360편·문제 1,440개입니다.
활동 1은 배우기, 활동 2는 익히기, 활동 3은 넓히기입니다.

| 단원 | 차시 | 내용 |
|---|---|---|
| 1. 낱말과 친해지기 | 1~10 | 낱말 뜻, 비슷한 말·반대말, 흉내 내는 말 |
| 2. 문장을 바르게 | 11~20 | 문장 짜임, 문장 부호, 꾸며 주는 말·이어 주는 말 |
| 3. 마음을 나타내는 말 | 21~30 | 감정 낱말, 마음 짐작하기, 마음 전하기 |
| 4. 중심 생각 찾기 | 31~40 | 중심 문장, 문단, 설명하는 글, 간추리기 |
| 5. 이야기를 읽어요 | 41~50 | 인물·때·곳, 일의 차례, 까닭, 옛이야기 |
| 6. 시를 느껴요 | 51~60 | 되풀이되는 말, 빗대는 말, 장면과 마음 |
| 7. 바르게 듣고 말해요 | 61~70 | 인사말, 높임말, 부탁·거절·칭찬 |
| 8. 내 생각을 말해요 | 71~80 | 사실과 의견, 까닭, 제안, 찬성과 반대 |
| 9. 우리말 바로 알기 | 81~90 | 맞춤법, 헷갈리는 말, 띄어쓰기, 낱말의 종류 |
| 10. 정보를 찾아요 | 91~100 | 안내문, 초대장, 표, 광고, 뉴스, 설명서 |
| 11. 글을 써요 | 101~110 | 일기, 편지, 소개·설명·의견 글, 고쳐 쓰기 |
| 12. 말과 책, 그리고 생활 | 111~120 | 속담, 우리말 표현, 책 읽기, 대본, 한글 |

문제 유형은 네 가지이며, 모두 **한 번 누르기**만으로 풉니다(끌기·타자·두 번 누르기 없음).

- 고르기 (보기는 매번 섞여 나옴)
- ○ × 고르기
- 문장 만들기 (낱말을 차례대로 누르기)
- 짝 맞추기 (왼쪽을 누르고 오른쪽 누르기)

## 접근성 기능

| 기능 | 위치 | 설명 |
|---|---|---|
| 글자 확대 | 위쪽 `가 − / 가 ＋` | 글자만 100~250% |
| 화면 확대 | 위쪽 `🔍 − / 🔍 ＋` | 버튼·그림까지 통째로 100~300%, 가로 스크롤 없이 다시 배치 |
| 화면 이동 버튼 | 오른쪽 아래 `▲ ▼` | 휠·두 손가락 스크롤이 어려울 때 눌러서 이동 |
| 머물러 누르기 | ⚙️ 설정 | 버튼 위에 포인터를 1~3초 올려 두면 저절로 눌림 |
| 누르자마자 선택 | ⚙️ 설정 | 단추를 누르는 순간 선택 (누른 채 미끄러져도 인정) |
| 떨림 방지 | ⚙️ 설정 | 0.4초 안의 연속 누름은 한 번으로 처리 (기본 켜짐) |
| 큰 마우스 포인터 | ⚙️ 설정 | 노란색 큰 화살표 |
| 터치 화면 누르는 방식 | ⚙️ 설정 | 바로 누르기 / 손을 뗀 곳 선택(댄 채 밀고 가서 떼기) / 0.5초·1초 꾹 누르기(스친 터치 무시) |
| 버튼 크기 | ⚙️ 설정 | 보통 / 크게 / 아주 크게 |
| 어두운 화면 | ⚙️ 설정 | 검정 바탕의 또렷한 색 |
| 소리로 듣기 | 위쪽 `🔊 듣기` | 글과 문제를 읽어 줌 (자동 읽기 설정 가능) |

터치패드·터치 화면·마우스·키보드(Tab, Enter, Space) 모두 쓸 수 있습니다.

## 편집 (선생님용)

1. 차시에 들어가 오른쪽 위 **✏️ 편집**을 누릅니다.
2. 제목, 학습 목표, 활동별 읽기 글과 문제를 고치거나, 문제·활동을 더하고 뺍니다.
3. **💾 저장**을 누르면 그 브라우저에 저장됩니다. **처음 내용으로 되돌리기**도 됩니다.

다른 컴퓨터로 옮길 때는 ⚙️ 설정 → **편집 내용 내보내기**로 파일을 받고, 옮긴 곳에서 **불러오기**를 누릅니다.
모든 학생에게 똑같이 적용하려면 `js/data1~6.js`(활동 1)와 `js/more1~6.js`(활동 2·3)를 직접 고칩니다.

## 인쇄

차시 첫 화면의 **🖨 인쇄**, 또는 단원 화면의 **🖨 단원 인쇄**를 누릅니다.

- 인쇄 글자 크기: 14pt / 18pt / 24pt / 32pt
- 범위: 한 차시 또는 단원 전체(10차시)
- 정답 표시: 선생님용 정답지

## 저장되는 정보

학습 기록, 설정, 편집 내용은 사용하는 브라우저 안(localStorage)에만 저장되며 어디로도 전송되지 않습니다.

## 사용한 오픈 소스

| 이름 | 용도 | 라이선스 | 저장소 |
|---|---|---|---|
| Pretendard | 읽기 쉬운 한글 글꼴 | SIL Open Font License 1.1 | https://github.com/orioncactus/pretendard |
| canvas-confetti | 차시를 끝냈을 때 축하 효과 | ISC | https://github.com/catdad/canvas-confetti |

두 가지 모두 `vendor/` 폴더에 라이선스 파일과 함께 들어 있어, 인터넷이 없어도 동작합니다.

## 파일 구조

```
index.html          화면 틀
css/style.css       모양
js/app.js           화면·활동·편집·접근성·인쇄
js/data1~6.js       120차시의 제목·목표·활동 1 (파일마다 20차시)
js/more1~6.js       120차시의 활동 2·3
vendor/             오픈 소스 (글꼴, 축하 효과)
```
